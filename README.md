Welcome to my **Tic-Tac-Toe** game built using **HTML, CSS, and JavaScript**!

## 🚀 Tech Stack

- **HTML**: Structured the game board and displayed game messages.
- **CSS**: Styled the board using clean and attractive colors and fonts.
- **JavaScript**: Handled the game's core logic and user interactions.

---

## 🎯 Features

✅ **Game Board UI**  
✅ **Winning Logic** (Rows, Columns, Diagonals)  
✅ **Draw Detection**  
✅ **Game Reset Functionality**
